# Overview

NordBanking operates as a RESTful API, processing requests and responses through JSON files.\
\
The NordBanking API seeks to build an inclusive and accessible experience for all users, regardless of personal context. It offers multilingual support and accessibility tools to make payment processing as intuitive as possible.&#x20;
